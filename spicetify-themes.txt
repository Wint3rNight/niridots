# Spotify theming. Active: Cathedral (our own colour scheme on Sleek's layout).
#
# Cathedral/color.ini is ours and IS tracked. Sleek's user.css is not - fetch it:
#   git clone --depth 1 https://github.com/spicetify/spicetify-themes.git \
#       ~/.config/spicetify/Themes/.official
#   mkdir -p ~/.config/spicetify/Themes/Cathedral
#   cp ~/.config/spicetify/Themes/.official/Sleek/user.css \
#      ~/.config/spicetify/Themes/Cathedral/
#   # color.ini comes from this repo
#   spicetify config current_theme Cathedral color_scheme Cathedral
#   spicetify backup apply
#
# Two schemes in color.ini: [Cathedral] blood-red accents, [Cathedral-Gilt] gold.
#   spicetify config color_scheme Cathedral-Gilt && spicetify apply
#
# AFTER EVERY SPOTIFY UPDATE (spotify-launcher auto-updates and reverts the
# patch): spicetify backup apply
#
# Tried and rejected: Glassify (glassmorphic, needed an npm build, did not suit
# the gothic look) and Frostify (no visible effect - targets an older Spotify
# DOM). Both removed.
